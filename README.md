# epycon
Python package for parsing and conversion EP signals recorded by Abbott WorkMate system.

Note: this is a slightly modified version of the original https://github.com/fnusa-icrc-ice/epycon.

Some additions:
1. parse PROC file to obtain study date, name, and institution,
2. get lowpass and highpass filters per channel,
3. channel references logic changed,
4. several new annotation groups for entries.log,
5. other smaller fixes.
